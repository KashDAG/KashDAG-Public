# KashDAG Protocol v2 engineering milestone — 2026-08-12

KashDAG has completed the engineering scope of Protocol v2. This milestone extends the protocol beyond the current public-testnet foundation while preserving explicit versioning, deterministic execution, state commitments, and fail-closed activation boundaries.

## Completed engineering scope

- Validator economics, delegation, unbonding, deterministic rewards, and validator-accountability mechanics
- Validator lifecycle and registry state
- Governance, treasury accounting, proposal voting, and controlled execution boundaries
- Fungible-token and non-fungible-asset transaction families
- Deterministic WASM deployment and invocation with bounded execution rules
- Versioned storage, migration, recovery, and unified state-commitment foundations
- Protocol-facing RPC, indexer, SDK, explorer, and wallet integration surfaces
- Cross-platform and multi-validator qualification paths for Protocol v2 behavior

## Activation boundary

Engineering completion is not network activation. The public testnet continues to identify Protocol v1 as authoritative until KashDAG completes and announces the coordinated Protocol v2 activation.

Activation requires an immutable release manifest, an approved activation checkpoint and parameters, qualified migration and rollback procedures, signed artifacts, matching validator state commitments, adversarial and recovery evidence, and the applicable independent reviews.

No Protocol v2 wallet control, RPC route, asset, governance action, staking action, or contract execution should be treated as live before the finalized activation checkpoint.

## What comes next

The next protocol work focuses on activation qualification, sustained public-testnet evidence, and M7 interoperability extension points. Proof-verifier interfaces and modular bridge-message verification remain gated and disabled until their trust assumptions, resource bounds, upgrade controls, and security requirements are approved.

KashDAG will publish Protocol v2 activation separately from this engineering-completion update.
